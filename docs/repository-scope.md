# Corporate repository scope

## Canonical responsibility

`HephzibahBehulahHQ.github.io` is the public gateway for Hephzibah Behulah and its five divisions: Elektroniker, Trading, Artificial Intelligence, Evangelism and Politics. It may present the company, link to the organization and divisions, and document public corporate information.

## Ownership map

| Topic | Canonical repository |
| --- | --- |
| AI-agent governance, security, testing and collaboration | [hb-AI-policy](https://github.com/HephzibahBehulahHQ/hb-AI-policy) |
| Visual tokens, approved assets and reusable components | [hb-design-system](https://github.com/HephzibahBehulahHQ/hb-design-system) |
| Division mission and domain guidance | The matching `hb-*` division repository |
| Product source, tests, deployment and product-specific rules | The matching product repository |

## Non-goals

Do not place product code, credentials, backend configuration, engineering specifications, financial advice, political research, Bible content, or operational AI policy here. Link to the responsible repository instead.

## Public-content safeguards

Keep claims current, attributable where needed and clear about whether a product is planned, available or verified. Preserve approved identity assets and the existing corporate visual presentation.
